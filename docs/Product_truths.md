# Refinzi

Refinzi is a workflow layer that sits between the user and AI.

It helps users externalize hidden intent and additional context without interrupting their workflow.

---

# Refinzi is NOT

* A chatbot
* A prompt marketplace
* A prompt engineering tool
* Grammarly
* A writing assistant

---

# Refinzi IS

* Ambient AI
* A workflow accelerator
* A context externalization layer
* A premium desktop utility

---

# Core Philosophy

AI is already intelligent.

The problem is that humans constantly have to interrupt their workflow to externalize additional context, refine wording, or better express their intent.

Refinzi reduces that interruption.

People do not necessarily want better AI.

People want less interruption.

# Design Principles

Premium feel is non-negotiable.

Every interaction should feel:

* Instant
* Calm
* Intentional
* Minimal

Avoid:

* AI jargon
* Feature overload
* Unnecessary animations
* Complex configuration screens

# Decision Filter

Before implementing any feature, ask:

* Does this reduce friction?
* Does this preserve flow?
* Would an AI-native user use this 20+ times per day?
* Does this make Refinzi feel more premium?
